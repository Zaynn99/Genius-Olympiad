Project Description
When Rivers Rise is an interactive, highly visual web dashboard designed to explore the global impact of flooding, identify high-risk zones, and demonstrate the engineering and technological solutions used to combat rising waters. Built with HTML, CSS, and vanilla JavaScript, the platform serves as an educational tool that brings together historical data, vulnerability analytics, and real-time forecasting simulations.

Problem Addressed
With climate change, rising sea levels, and increasingly extreme weather events, flooding is one of the most destructive natural disasters globally. However, the sheer scale of the threat, the specific structural vulnerabilities of different regions, and the technology used to predict these events can be difficult to conceptualize. This project addresses the gap in public awareness by transforming complex geographical and statistical data into accessible, engaging, and interactive visualizations.

Features
Interactive Global Risk Map: A Leaflet.js-powered map detailing 315 critical flood danger zones and 63 historical disaster epicenters, complete with historical context and data.

Vulnerability Analytics: A searchable database that allows users to look up any country to see its specific flood threat vectors and the percentage of its population exposed. It features dynamic data visualizations powered by Chart.js.

Advanced Flood Simulator: A custom Canvas-based interactive sandbox where users can design topographies, place water sources, and run physics-based simulations to observe how water spreads based on elevation and soil permeability.

Automated Forecasting Terminal: A real-time simulation of a telemetry network that monitors simulated river capacities, calculates fluctuations, and automatically triggers flash flood warnings when absolute thresholds are breached.

Responsive Design: A cohesive, dark-themed UI that works seamlessly across different screen sizes.

How to run the project
Because this project consists of purely static frontend files (HTML, CSS, and JavaScript), there is no need to install dependencies, set up a local server, or configure a database.

Download/Clone the repository to your local machine.

Ensure all HTML files are located in the same folder.

Open Main.html in any modern browser 

Use the main dashboard buttons to navigate between the interactive modules.

AI Usage
During the development of this project, AI tools were utilized to accelerate the workflow and enhance the educational content. Specific use cases included:

Data Compilation: Assisting in the research and formatting of the extensive arrays of historical flood data, geographical coordinates (latitude/longitude) for the Leaflet map, and country-specific vulnerability statistics.

Code Generation & Logic: Helping to draft boilerplate HTML/CSS for the glassmorphism UI design, and assisting with the complex JavaScript logic required for the grid-based canvas flood simulator and the randomized telemetry terminal.

Debugging: Identifying and resolving minor syntax errors and CSS layout issues during the styling process.
